# べんきょう（個人用の勉強アプリ）

開くとすぐに「次にやること」と「スタート」ボタンが出る、スマホ向けのWebアプリです。データはこの端末のブラウザ（localStorage）だけに保存され、外には送りません。

## できること
- **3つのリスト**：やらなきゃ（締切・所要時間の目安つき）／やりたい（締切なし）／いまやってる（進行中）
- **自動スケジュール**：時間割と曜日ごとの「勉強に使える時間帯」から空き時間を出し、締切が近い「やらなきゃ」から順に入れる。余った時間に「やりたい」を、今週使った時間が少ない分野から入れる。1日の最後には必ず「だらだら時間」を入れる
- **手で調整**：予定のブロックをタップして、時刻の変更・前後の入れ替え・タスクの差し替え・「ここを空ける」ができる。手で変えたブロックには 📌 がつき、組み直しても動かない。その日だけの予定（サークルなど）も入れられる
- **ポモドーロ**：25分集中＋5分休憩（4回ごとに15分の長い休憩。どれも設定で変更可）。集中が終わると「完了した？」と聞く。画面を消していても、戻ったときに時間がずれない
- **記録**：今日の集中の合計、1週間の分野別（英語・フランス語・データサイエンス・政治経済）の時間、完了したタスク

## 使い方
1. GitHub Pages で公開し、スマホで `…/study/` を開く
2. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「アプリをインストール」
3. ⚙ 設定で時間割（駒場の1〜6限から選べる）と、勉強に使える時間帯を登録
4. リストにタスクを追加すると、予定が自動で組まれる

## 注意
- ブラウザの「閲覧データを削除」でデータが消えることがあります。⚙ 設定 →「バックアップを保存」でときどきJSONを保存してください。
- iPhone では、ほかのアプリを開いている間はタイマーの音が鳴らないことがあります（アプリに戻ったときに時間は正しく進んでいます）。「タイマー中は画面を消さない」をオンにして、画面を開いたまま使うのがおすすめです。
