同期（Googleドライブ）

複数の端末で同じ帳簿を使うための機能です。オフラインの間はそれぞれの端末に保存され、ネットにつながったときに自動でまとめられます。データはあなたのGoogleドライブの、このアプリ専用の非表示フォルダに保存されます。

初回設定（Google クライアントID）
  1. このアプリを HTTPS で公開する（例：GitHub Pages）。index.html を直接開いた状態では同期できません。
  2. Google Cloud Console でプロジェクトを作り、「Google Drive API」を有効にする。
  3. 「OAuth 同意画面」を設定し、テストユーザーに自分のGoogleアカウントを追加する。
  4. 「認証情報」→「OAuth クライアントID」→種類「ウェブアプリケーション」。「承認済みの JavaScript 生成元」に公開したURL（例：https://ユーザー名.github.io）を登録する。
  5. 表示されたクライアントIDを下に貼り付けて保存。各端末で1回ずつ設定します。

データ

データはこの端末のブラウザ内（IndexedDB）に保存され、ネットがなくても使えます。端末の故障やブラウザのデータ削除に備えて、定期的にバックアップしてください。

JSONファイルを読み込む

「合体」はこの端末のデータを残したまま、ファイル側の入力を追加・更新します。Googleを使わずに、別の端末のデータを手作業でまとめたいときに使います。
