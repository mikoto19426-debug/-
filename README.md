# オフライン会計

ネットがなくても使える、ブラウザだけで動く会計（帳簿）アプリです。サーバー不要・インストール不要。

## 特長
- **オフラインで入力・保存**：データは端末内のブラウザ（IndexedDB）に保存されます。外部に送信されません。
- **収入 / 支出 / 振替**（口座間の移動）を記録
- **一覧**：月・種類・キーワードで絞り込み、編集・削除
- **集計**：月別・年別の収支、科目別内訳、口座残高
- **設定**：口座（期首残高）・科目の追加/削除
- **バックアップ**：JSONで保存・復元、CSV書き出し（Excel対応のBOM付きUTF-8）
- スマホのホーム画面に追加してアプリのように使えます（PWA）

## 使い方
1. いちばん簡単：`index.html` をブラウザで開く（そのまま入力・保存できます）
2. アプリとしてオフライン起動したい場合：HTTPSで配信（例：GitHub Pages）し、一度開いてから「ホーム画面に追加」。以後はネットなしで起動できます。
   ローカルで試すなら `python3 -m http.server 8000` → http://localhost:8000/

## 注意
- データはそのブラウザ・その端末にだけ保存されます。別の端末とは自動同期されません（JSONバックアップで移せます）。
- ブラウザの「閲覧データを削除」でデータが消えることがあります。**定期的にJSONバックアップを取ってください。**
