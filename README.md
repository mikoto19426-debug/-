# オフライン会計

ネットがなくても使える、ブラウザだけで動く会計（帳簿）アプリです。サーバー不要・インストール不要。

## 特長
- **レジ（屋台向け）**：メニューをタップして注文、個数は＋／−でも数字入力でも変更、整理券番号は自動で次の番号（手で変更も可）、お預かり金額からおつりを計算、「会計して追加」で売上に記録
- **本日の注文**：整理券番号を大きく表示、「お渡し」済みの管理
- **メニュー設定**：メニューの追加・値段の変更・売り切れ・削除（メニューも同期されます）
- **オフラインで入力・保存**：データは端末内のブラウザ（IndexedDB）に保存されます。外部に送信されません。
- **収入 / 支出 / 振替**（口座間の移動）を記録
- **一覧**：月・種類・キーワードで絞り込み、編集・削除
- **集計**：月別・年別の収支、科目別内訳、メニュー別売上（個数・金額）、口座残高
- **設定**：口座（期首残高）・科目の追加/削除
- **同期（Googleドライブ）**：複数の端末で同じ帳簿を使えます。オフライン中は各端末に保存し、ネットにつながったら自動でまとめます
- **バックアップ**：JSONで保存、「合体して取り込む」または「置き換えて復元」、CSV書き出し（Excel対応のBOM付きUTF-8）
- スマホのホーム画面に追加してアプリのように使えます（PWA）

## 使い方
1. いちばん簡単：`index.html` をブラウザで開く（そのまま入力・保存できます）
2. アプリとしてオフライン起動したい場合：HTTPSで配信（例：GitHub Pages）し、一度開いてから「ホーム画面に追加」。以後はネットなしで起動できます。
   ローカルで試すなら `python3 -m http.server 8000` → http://localhost:8000/

## 複数端末での同期
- 取引・口座・科目ごとに最終更新時刻を記録し、削除も「削除した」という記録として残します。2台のデータを合わせるときは、同じ取引なら新しい方を採用するので、どちらの端末で入力した分も消えません。
- 同じ取引を2台で別々に編集した場合は、あとで編集した方が残ります。
- Googleドライブ同期を使うには、アプリをHTTPSで公開し、Google Cloud でクライアントIDを作る必要があります（手順はアプリの「設定 → 同期 → 初回設定」に書いてあります）。
- Googleを使わない場合は、片方で「バックアップ（JSON）」→もう片方で「合体して取り込む」で、手作業でまとめられます。

## 注意
- ブラウザの「閲覧データを削除」でデータが消えることがあります。**定期的にJSONバックアップを取ってください。**
